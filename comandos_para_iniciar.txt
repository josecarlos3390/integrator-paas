============================================================
COMANDOS PARA INICIAR EL INTEGRADOR (instalacion nativa, sin Docker)
Servidor: SRVGLPI01 - Windows Server 2016
============================================================

--- Servicios de infraestructura (ya son servicios de Windows,
    arrancan solos con el servidor; solo verificar) ---

PostgreSQL 16   : servicio "postgresql-x64-16"  (puerto 5434)
RabbitMQ        : servicio "RabbitMQ"           (puertos 5672 / 15672)
Seq             : servicio "Seq"                (puerto 5341)

Para verificar su estado (PowerShell):
  Get-Service postgresql-x64-16, RabbitMQ, Seq

Para iniciarlos si estuvieran detenidos (PowerShell como admin):
  Start-Service postgresql-x64-16
  Start-Service RabbitMQ
  Start-Service Seq


--- Integrador: API y Worker (SERVICIOS DE WINDOWS) ---

Integration.Api    : servicio "Integration.Api"     (puerto 5000, inicio automatico)
Integration.Worker : servicio "Integration.Worker"  (inicio automatico)

Ambos arrancan solos con el servidor y se reinician solos si fallan
(3 reintentos, 60s entre cada uno). Los binarios que corren son los
publicados en .publish\ (NO dotnet run desde src\).

Para verificar su estado (PowerShell):
  Get-Service Integration.Api, Integration.Worker

Para reiniciarlos (PowerShell como admin):
  Restart-Service Integration.Api
  Restart-Service Integration.Worker

Para instalarlos/desinstalarlos (PowerShell como admin):
  powershell -ExecutionPolicy Bypass -File scripts\install-windows-services.ps1
  powershell -ExecutionPolicy Bypass -File scripts\install-windows-services.ps1 -Uninstall

IMPORTANTE - despues de un git pull con cambios de codigo:
  dotnet publish src\Integration.Api -c Release -o .publish\Api
  dotnet publish src\Integration.Worker -c Release -o .publish\Worker
  Restart-Service Integration.Api
  Restart-Service Integration.Worker

Logs del integrador: Seq en http://localhost:5341 (los servicios no
tienen consola, toda la traza va a Seq).


--- Verificacion rapida ---

API viva:        curl http://localhost:5000/health/live
API lista:       curl http://localhost:5000/health/ready
RabbitMQ admin:  http://localhost:15672  (guest / guest)
Seq logs:        http://localhost:5341


--- Comandos utiles del flujo VENDOR_BANK_ALERT ---

Backfill/reset baseline de proveedores (tenant RETAIL):
  curl -X POST "http://localhost:5000/api/admin/vendor-bank/baseline?tenantId=RETAIL"
  (agregar &overwrite=true para resetear todos los baselines)
